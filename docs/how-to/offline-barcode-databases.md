# How-to: answer barcode scans on the phone

Settings → **Offline barcode lookup**.

1. Download **US packaged foods (USDA)** — 440,275 barcodes, 22 MB,
   public domain. If you download one, make it this one.
2. Optionally add the **Open Food Facts US slice** — 927,505 products,
   47 MB, ODbL; its attribution travels inside the file.

Each download is checked against a published checksum before it installs,
resumes if interrupted, and can be deleted any time — nothing else in the
app changes, and you can download it again later.

With a database installed, a scan is answered on your phone — airplane
mode, dead zone, anywhere — and every answer names its source. A code
neither database knows shows one button: **Ask openfoodfacts.org**. Only
that tap sends the digits (the full map: Settings → What leaves your
device).

The web app has no downloadable databases — browser storage isn't a
reliable home for files this size — so scans there ask online, with the
same one-tap consent.
